# Echofang source register

The detailed asset register lives at [`assets/SOURCES.md`](assets/SOURCES.md). This root copy exists so a release review can find provenance next to `DESIGN.md` and `DECISIONS.md`.

The vertical slice intentionally ships hand-authored, runtime-generated vector silhouettes and environment paintings instead of unreviewed generative output. No third-party binary art, sound, fonts, or music are embedded. Before full-release content is imported, add the generator or artist, model/version, prompt or session reference, date, and license to `assets/SOURCES.md`.
